# Paperfolio 文献书房

用于 Windows 的本地文献库。导入 PDF 后，双击论文即可连续滚动阅读、选文高亮、记笔记，或生成带页码的论文导读。

## 下载安装

[下载 Windows x64 安装包](https://github.com/wenbatang/Paperfolio/releases/latest/download/Paperfolio-Setup-x64.exe) · [全部版本及 SHA-256 校验值](https://github.com/wenbatang/Paperfolio/releases)

运行 `Paperfolio-Setup-x64.exe` 后点 **浏览…** 选择可写的安装目录。首次安装会联网准备 Python 3.12 和阅读组件。以后双击该目录的 `Paperfolio.exe` 即可启动。使用源码时，双击 `start.cmd`。

左侧 **设置** 可更改书房背景、新附件保存位置，以及另存 PDF、高亮副本和 BibTeX 的默认目录。保存文件时仍可另选位置。换一篇论文或从多选返回时，右侧会继续显示上次打开的 **附件**、**笔记** 或 **条目信息** 栏目。

安装排版引擎、配置微软或 Google 翻译，以及部署本地导读模型，见 [翻译与导读安装教程](SERVICES.md)。

## 整理与阅读

文献库固定在主窗口第一个标签。原文、译本、导读中的页码链接都在同一窗口打开；同一附件只占一个标签。用顶部 **标签页** 菜单查看完整标题和切换，鼠标中键可关闭阅读标签。

阅读器的 **导航** 可展开 PDF 自带目录，也可添加个人页书签。书签按附件保存。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+Z / Ctrl+Y 或 Ctrl+Shift+Z | 撤销 / 重做。本次运行按操作顺序记住最近 100 次文献整理、笔记、高亮和书签变更；一次批量整理算一步 |
| Ctrl+A / Shift+F10 | 在文献列表中全选当前结果 / 打开所选文献菜单 |
| Ctrl+Tab / Ctrl+Shift+Tab | 下一个 / 上一个标签 |
| Ctrl+W / Ctrl+Shift+T | 关闭 / 重新打开阅读标签 |
| Ctrl+O / Ctrl+F | 导入 PDF / 搜索当前文献库或 PDF |
| Ctrl+D / Ctrl+G | 切换当前页书签 / 输入跳转页码 |
| Ctrl+Shift+N | 为当前页或选文记笔记 |
| Ctrl++ / Ctrl+− / Ctrl+0 | 放大 / 缩小 / 适宽 |
| F1 | 查看快捷键 |

- 左栏的 **＋** 可建立分类。在分类中导入的新文献会自动归类，也可在 **条目信息 → 编辑信息与分类** 中调整分类、作者、年份、DOI 和标签。
- 点 **多选** 后逐篇点选，或直接用 **Ctrl+点击** 选不相邻的文献、**Shift+点击** 连续选择。右键任一选中项，选 **移入分类**，可指定已有分类或新建分类。也可把选区直接拖到左栏的分类名称或 **未分类** 上。多选时右侧提供归类、星标、合并导出 BibTeX 和移入回收站等操作。在 **回收站** 可以批量恢复。按 **Esc** 清空选区并退出多选。
- 标题、作者取自 PDF 元数据。缺少标题时采用文件名。年份初值取自文件创建日期，正式引用前可改为发表年份。DOI 从首页文字提取。
- 搜索支持标题、作者、年份、DOI 和标签。按列头排序，点星号收藏。回收站可恢复条目。再次导入内容相同的文件会复用原条目。
- 原文和译本都支持上下连续滚动、缩放、页码跳转和全文查找。沿同一页的文字拖动，可逐字或跨行选择，松开后可以直接复制、记笔记，或选择五种颜色之一高亮。
- 连续标注时，在 **荧光笔** 菜单选一个颜色，此后每次拖选都会保存高亮。选 **普通选文** 可恢复弹出工具条。右键已标文字可改色、摘录或删除。打开 **高亮列表** 可按页浏览、定位原文、将摘录写入笔记，或导出含标准 PDF 高亮批注的副本。高亮按附件保存在本地文献库。
- 在条目的 **笔记** 页可预览笔记或双击返回原页。右键某条笔记选 **删除笔记**，也可以选中后按 **Delete** 或点 **删除所选笔记**。
- **附件** 页按实际存在的本地 PDF 列出原文、译文和双语版，译本按生成时间从新到旧排列。在文件夹里删除或放回附件后，打开着的面板会自动更新，也可点 **刷新**。放回同一路径后会恢复原来的笔记和阅读进度。原文缺失时，重新导入同一份 PDF 即可补回。
- 不同附件分别记忆最后阅读页。**附件 → 另存为…** 可导出原文或译本，右键文献可导出当前选区的 BibTeX。

## 翻译

默认从英语译为简体中文。页码留空处理全文，输入 `1,3-5` 处理选页。从原文阅读器发起翻译时，会预填当前页，可清空后翻译全文。

| 模式 | 处理方式 | 适用文档 |
| --- | --- | --- |
| PDF2Zh · 保留排版 | 调用 PDFMathTranslate-next 2.10.2 和 BabelDOC 分析版面，在原页结构上排入译文，并生成双语版 | 有公式、图表或多栏排版的论文 |
| 段落对照 · 重排译文 | 文献书房按页提取文字块，交给所选翻译服务。左侧放原页，右侧重新排印译文，长译文可续页 | 想先试译几页、摘读正文或核对术语的文字型 PDF |

两种模式均支持本机 Ollama、微软 Azure Translator 和 Google Cloud Translation。选择本机服务时，翻译窗口会在后台检测 Ollama，必要时启动服务。在 **本机模型** 中选定的模型会保存在当前文献库，后续翻译和论文导读都会沿用。首次使用或已选模型被卸载时，自动选取 Ollama 列表中的第一个可用文本模型。安装新模型后点 **重新检测**。程序也会记住上次启动翻译时所用的服务。

本机保留排版模式使用 BabelDOC 排版引擎和 Ollama，并缓存完成的文字块。窗口显示引擎阶段、当前阶段的完成数、耗时和当前段落已生成的字符数。遇到空回复或输出截断，程序会单独重试该块，较长的文字会拆短。重试仍失败的块保留原文，完成提示和附件名称会标出数量。再次翻译时可复用成功缓存，并重新尝试这些块。连接故障或全部文字块失败时会提示任务失败。首次使用排版引擎可能需要联网下载模型和字体，扫描件需先做 OCR。

保留排版模式也可选 **PDF2Zh 配置文件**，载入已有的 PDF2Zh 2.x TOML 配置。模型、凭据和服务地址由该配置提供，使用云服务时文字会发送到所配置的服务。翻译窗口显示运行日志，任务运行期间仍可在主窗口阅读。成功后，两份 PDF 会加入条目的 **附件** 页。每次翻译独立归档。

上游项目及配置说明见 [PDF2Zh](https://github.com/PDFMathTranslate/PDFMathTranslate)、[PDFMathTranslate-next](https://github.com/PDFMathTranslate/PDFMathTranslate-next) 和 [命令行文档](https://github.com/PDFMathTranslate/PDFMathTranslate-next/blob/main/docs/en/advanced/advanced.md)。

## 论文导读

打开 **条目信息 → 论文导读**。首次打开会自动连接本机 Ollama，服务未运行时会尝试启动，窗口显示当前阶段和模型。程序从原文选取片段，生成研究背景、创新亮点、方法对比和可扩展方向。点页码可跳到原文，勾选 **显示原文摘录** 可核对依据。“延伸设想”是模型依据论文提出的学习或实验建议。再次打开会直接显示已保存的导读，点 **重新生成** 可更新。

## 翻译效率与占用

**填入正文页** 可根据书签或末尾章节标题选取页码。参考文献与结论共用一页时会保留该页，开始前可修改范围。段落模式在 `data/paragraph-cache.sqlite3` 中记录成功的译文，按文字内容、模型版本、语言与提示词匹配。重复段落或重试可直接复用。本机排版模型从磁盘直接加载，限制推理线程并关闭线程空转。Ollama 请求使用 30 秒空闲保留时间。

## 文件与安装

书目、标签、笔记、设置和阅读位置保存在 `data/library.sqlite3`。默认原文位于 `data/attachments/`，译本位于 `data/translations/`。更改保存位置后，新附件使用新目录下的 `attachments` 和 `translations` 子目录，已有附件沿用原路径。备份时退出程序，复制 `data` 及曾使用过的外部附件目录。恢复外部目录时保留原路径。

本机使用项目内的 `.venv`。换机或移动项目后，可使用带 Tk 的 Python 3.12 和 `setup.ps1` 重建虚拟环境。脚本优先使用 uv，也支持 Python 自带的 venv 和 pip。若当前网络无法连接默认 PyPI，可在项目目录指定镜像。

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1 -IndexUrl https://pypi.tuna.tsinghua.edu.cn/simple
.\start.cmd
```

构建 Windows 安装包时，从项目目录运行 `powershell -ExecutionPolicy Bypass -File .\packaging\build.ps1`。需要 Windows x64、.NET Framework 4.x 编译器和 uv。构建脚本支持通过 `-Uv` 和 `-UvLicenses` 指定 uv.exe 及其许可证目录。安装包和 SHA-256 校验文件会生成在 `dist`。安装包内含项目源码、启动器及附带许可证的 uv，不包含个人文献库。
